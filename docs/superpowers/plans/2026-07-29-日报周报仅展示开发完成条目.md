# 日报/周报仅展示「开发完成」条目 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 日报和周报的需求开发、缺陷修复、其他板块仅展示任务状态为「开发完成」或「任务完成」的条目。

**Architecture:** 渲染时过滤（方案 A）。新增 `filterCompleted` 纯函数，在 `buildReportMarkdown`（日报）和 `buildWeekReportMarkdown`（周报）的渲染阶段过滤条目。`extractDeveloperReportData` 返回的原始列表不变，保护 `send-email.js` 抄送逻辑。`completedTaskStatuses` 全局扩展为包含「任务完成」，连带影响 `achievedItems` 和缺陷来源信息。`monthlyDemandProgress.completedCount` 采集时改用 `completedTaskStatuses`。

**Tech Stack:** Node.js, xlsx, mocha + chai

## Global Constraints

- 过滤条件：`taskStatus` 为「开发完成」或「任务完成」，两者等效
- 渲染时过滤，不修改 `extractDeveloperReportData` 返回的原始列表（`demands`/`ppDefects`/`nonPpDefects`/`migrations`/`packs` 等）
- `send-email.js` 抄送逻辑零影响
- 测试栈：mocha + chai，`npm test` 运行 `mocha test/*.test.js`
- 测试文件按源文件命名约定：`test/generate-report-kf.test.js`
- commit message 使用中文，前缀「功能：」
